Варианты дизайна портфолио

Одни и те же проверенные данные, пять разных решений. Все — светлая + тёмная тема по системной настройке, адаптив до 375 px.

  1. Сессия запросаT-SQL-запрос в hero, результат — таблица; каждый раздел — result set. IBM Plex.
  2. ER-диаграммаHero — схема базы с таблицами и связями 1:N, клик по таблице ведёт к её строкам.
  3. План выполненияСтраница как execution plan: операторы с процентами стоимости, заголовки разделов — всплывающие подсказки SSMS.
  4. Скрипт ↔ результатПереключатель: профиль как T-SQL DDL и INSERT-ы с подсветкой, либо те же данные таблицами.
  5. Даташит AK-2026Паспорт на компонент: features, ratings, characteristics, pin configuration, revision history. Archivo.
  6. Редакционный, ДніпроБез метафор: кириллическая типографика Piazzolla + Commissioner, переключатель Укр/Eng, линия реки на полях.
